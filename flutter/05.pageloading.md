1. 创建riverpod全局变量
```js
final pageLoadingProvider = StateProvider<bool>((ref) { return true; })
```

2. 页面中监听数据变量
```js
// 在Build中监听
final pageLoading = ref.watch(pageLoadingProvider);


 home: Stack(
        children: [
          HomeScreen(),
          if (pageLoading)
            Positioned.fill(
              child: Container(
                color: Colors.black.withAlpha(200),
                child: Center(
                  child: CircularProgressIndicator(color: Colors.white),
                ),
              ),
            ),
        ],
      ),
    );
```

3. initState 中加载接口

```js
Future<void> _loadData() async {

  ref.read(pageLoadingProvider.notifier).state = true;

  final res = await fetch();

  ref.read(pageLoadingProvider.notifier).state = false;

}

@override
initState() {
  super.initState();
  _loadData();
}

```
