
1. 下载插件
```flutter pub add flutter_launcher_icons```

2. yaml 中配置一下
```yaml
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon.png"

  web:
    generate: true
    image_path: "assets/icon.png"

  windows:
    generate: true
    image_path: "assets/icon.png"

  macos:
    generate: true
    image_path: "assets/icon.png"

  linux:
    generate: true
    image_path: "assets/icon.png"
```

3. 执行生成
```dart run flutter_launcher_icons```
