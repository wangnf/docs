# 技术文档

这是使用 [mdBook](https://rust-lang.github.io/mdBook/) 构建的个人技术文档。

文档按主题分为：

- **工作**：项目、设备和日常工作记录
- **Flutter**：Flutter 开发与基础示例
- **Linux / Python / SVN**：常用开发技术
- **WebGL / 网页**：前端与三维开发
- **英文 / 工具**：学习资料与环境工具

本地预览：

```bash
mdbook serve
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

部署说明和私有仓库的免费托管选项见仓库根目录的 [在线发布](https://github.com/wangnf/docs/blob/main/DEPLOYMENT.md)。
